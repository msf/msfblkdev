# Project instructions

- Use simplified technical English in every response and in all project prose.
- Use direct sentences with one clear idea. Prefer active voice and name the actor.
- Use one term for each concept. Do not rotate synonyms.
- Separate procedures from descriptions. Start each procedure step with an imperative verb and include its expected result.
- Preserve literal commands, code, API names, flags, paths, and log messages.
- State whether a claim is verified, measured, inferred, or proposed.
