Source: 140fc81173fdb480bd33d11d19e7d2fcfbf0eab8 plus tests/reclaim.rs module registration
and new tests/reclaim/descriptor_survival.rs. See transcript for source and ELF SHA-256.

Model: 8 logical blocks, 12 segments of 8 blocks, 4 KiB blocks. Write LBAs 0..2 twice:
first values 1/2/3, then 10/11/12 (little-endian u32 repeated across each block). Flush.
Publish A until segment 0 is pending on disk. No subsequent client writes. Two children
start from copies of A. Stop one after B's records fsync, one after B's descriptor write.
A failed descriptor fsync adds no guarantee: the crash image can retain the old slot or
the completed new descriptor. The test requires the cuts to agree on every other byte.
Open a fresh copy of each image; check selected root, segment 0's state and all 8 LBAs.
The control rewrites a block still needed by A; reading flushed LBA 0 must detect damage.

Limits: one fixture, one pending 4 KiB write assumed atomic for this model. No physical
power cut, simulated io_uring implementation, injected errno or control of thread scheduling.
This control does not independently traverse every reference reachable from every root.
